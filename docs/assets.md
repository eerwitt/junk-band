# Asset provenance

`public/sprites.png` is original generated starter artwork, produced with the built-in image generation tool for this project. It is a four-quadrant transparent sprite atlas: tin can, rubber duck, bottle and matchbox. It never represents actual SAM segmentation.

Generation prompt: “Create a production sprite atlas for JUNK, a sunny surreal musical paper-puppet instrument. Actual transparent background. Exactly four separate objects in an evenly spaced 2 by 2 grid, each entirely inside its own equal quadrant with generous transparent padding; no overlap, no ground shadows, no words. Top left: a battered silver tin can with a burnt orange paper label and two tiny wire legs. Top right: a charming ochre yellow rubber duck toy with two skinny dark paper legs. Bottom left: a tall sea-glass mint green glass bottle with a small cream label and two tiny dark paper feet. Bottom right: a vintage burnt orange and ivory matchbox with a single match sticking up, tiny paper feet. Original sophisticated handmade stop-motion collage art: real photographed material textures mixed with slightly irregular bold black ink outlines and cut paper edge, editorial object photography, warm directional sunlight, playful awkward charm. Front three-quarter view, readable silhouettes, fully isolated alpha. Do not depict UI, environment, circles or backgrounds. All four characters roughly same total height, centred in their own quadrant. This is artwork for starter synthesized sounds, not evidence of extraction.”

`src/audio/demo.ts` synthesizes four deterministic original starter samples: low thump, noisy snare, tuned glass tone and high tick. There are no third-party music recordings. Both starter grooves use those same samples with different arrangement and tempo. The browser labels them synthesized demo sounds. A real recording must be supplied and evaluated before any real-object extraction demo.

Noto Sans is self-hosted for Godot and browser controls. Its embedded metadata identifies Copyright 2015–2021 Google LLC and the SIL Open Font License 1.1; the full license is included at `godot/assets/OFL.txt`. The original font file was reused from the local project asset library without modification. There are no React icon or Fontsource dependencies in the current build.

Three unmodified npm archives are included under `vendor/` for offline installation; each retains its upstream license. See `vendor/README.md` and the root integrity lockfile. Research SAM dependencies have separate licenses; their weights are never bundled. Review the upstream SAM License and relevant HF conditions before deployment.

The play/pause, tempo arrows, pencil, eraser, paging, save and skull icons are original code-native SVG geometry. Impact words use original monoline glyph strokes in `godot/scripts/landing_effect.gd`, with small per-letter variation; no extra font or image service is required. The landing plop is an original, quiet falling-pitch oscillator generated in the browser and is separate from the exported musical arrangement.
